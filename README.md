Описание

Реляционная база данных для управления системой проката и бронирования автомобилей. Хранит информацию об автопарке, пунктах проката, пользователях и их ролях, договорах аренды и оформленных бронированиях.

Структура базы данных

Таблицы

roles — Роли пользователей
• id — уникальный идентификатор роли
• name — название роли (Клиент / Менеджер / Администратор)

clients — Пользователи системы (Клиенты и сотрудники)
• id — уникальный идентификатор пользователя
• full_name — ФИО пользователя
• phone — контактный номер телефона
• driver_num — номер водительского удостоверения
• role_id — внешний ключ на таблицу roles (по умолчанию 1 — Клиент)

rental_points — Пункты проката
• id — уникальный идентификатор пункта проката
• city — город расположения
• address — адрес пункта проката
• working_hours — график работы
• capacity — вместимость автопарка (количество парковочных мест)
• manager_id — внешний ключ на таблицу clients (закрепленный менеджер пункта)

cars — Автомобили
• vin — уникальный 17-значный идентификационный номер автомобиля (первичный ключ)
• brand — марка автомобиля (Toyota, Hyundai, BMW и т.д.)
• model — модель автомобиля
• release_year — год выпуска
• mileage — текущий пробег (км)
• point_id — внешний ключ на таблицу rental_points (пункт приписки автомобиля)

rental_contracts — Договоры аренды
• id — уникальный идентификатор договора
• car_vin — внешний ключ на таблицу cars (арендуемый автомобиль)
• pickup_point_id — внешний ключ на таблицу rental_points (пункт выдачи автомобиля)
• return_point_id — внешний ключ на таблицу rental_points (пункт возврата автомобиля)
• start_date — дата начала аренды
• end_date — дата окончания аренды
• status — текущий статус договора (Создан, Активен, Завершен)

bookings — Бронирования клиентов
• id — уникальный идентификатор бронирования
• client_id — внешний ключ на таблицу clients (клиент, оформивший бронь)
• contract_id — внешний ключ на таблицу rental_contracts (связанный договор аренды)
